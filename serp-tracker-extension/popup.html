Amazon does not show search volume on the search page. Import it from your own report:

  • Search Query Performance (Seller Central → Brands → Brand Analytics): uses the "Search Query Volume" column.
  • Any CSV with a keyword column ("Search Query", "Search Term" or "Keyword") and a "Search Volume" column.
  • Brand Analytics "Search Frequency Rank" is kept too, but it is a rank, not a volume.

Daily searches = weekly volume ÷ 7 (or monthly ÷ 30). It is an average day, not a live count.
